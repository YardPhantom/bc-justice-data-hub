Review accounting

Automatic scheduling

Use tools\setup-scheduled-tasks.cmd to create daily court-list, weekly Catalogue, and monthly statistics tasks.

Edit data/collection-policy.json, then run tools\collect-new.cmd for normal updates. Use tools\collect-all.cmd only for a forced full refresh. See Automatic scheduling.

Data protection

Automatic collection backups

Before a collection or import command changes SQLite, the system creates an integrity-checked backup in backups\database. Collection stops if that backup fails. The latest 20 backups are retained by default.

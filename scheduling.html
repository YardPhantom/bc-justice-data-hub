Windows Task Scheduler

Automatic collection schedule

Create three local tasks that keep court lists, Catalogue resources, and statistics current.

Private local tasksTasks run under your Windows account and write logs locally.
Daily court lists6:30 AM
Weekly CatalogueSunday 7:00
Monthly statisticsDay 1, 8:00

One-time setup

Create scheduled tasks

Run this from the site folder. Use Run as administrator only if Windows denies task creation.

tools\setup-scheduled-tasks.cmd

Daily court lists

Runs scheduled-daily-courts.cmd, archives current court lists, exports dashboard data, and updates alerts.

Weekly Catalogue

Runs an incremental BC Data Catalogue download and imports only new or changed resources.

Monthly statistics

Refreshes corrections oversight, police data, Statistics Canada crime data, comparisons, and exports.

Maintenance

Test or remove tasks

tools\run-scheduled-tasks-now.cmd starts all three tasks immediately.

tools\remove-scheduled-tasks.cmd removes all three tasks.

Latest task logs are saved in reports\scheduler.

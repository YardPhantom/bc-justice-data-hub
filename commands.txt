START HERE

.\command.cmd

TOOLS\COLLECT-NEW.CMD
--------------------
tools\collect-new.cmd
  Collect new or changed data, publish initial exports, then run only the required post-processing automatically.

Switch: --quick
  Check metadata first and skip heavy unchanged work where supported.

Switch: --force
  Redownload and reimport supported sources and force downstream rebuilds.

Switch: --skip
  Skip the pre-collection database-backup prompt and continue without creating a backup.

Switch: --wait
  Keep Collect New open until automatic identity or non-identity post-processing and final exports are complete.

TOOLS\COLLECT-ALL.CMD
--------------------
tools\collect-all.cmd
  Force a complete Catalogue, justice, judgment and statistics refresh followed by exports.

Switch: --term "TEXT"
  Limit the Catalogue stage to an override search term; repeat for multiple terms.

Switch: --limit N
  Limit unique Catalogue datasets for a controlled full-refresh test.

Switch: --verbose
  Show detailed Catalogue URLs, downloads and skip reasons.

Switch: --quick
  Allow the Catalogue stage to skip unchanged downstream work; other full collectors still run.

Switch: --force
  Explicitly force the Catalogue stage in addition to the command's built-in full refresh.

Switch: --incremental
  Limit the Catalogue download stage to changed resources while other full collectors still run.

SETUP AND MAINTENANCE
--------------------
tools\setup.cmd
  Install dependencies, initialize or migrate the database, build exports and install the Search API helper.

Switches: none
  This command uses the standard setup workflow.

tools\setup-data.cmd
  Install data-import dependencies, initialize or migrate SQLite, and build initial exports.

Switches: none
  This command uses the standard data setup workflow.

tools\maintenance.cmd
  Run normal maintenance, safe backup handling, validation and storage cleanup.

Switch: --full
  Also run slow SQLite VACUUM and exhaustive duplicate-file hashing.

tools\backup-db.cmd
  Create an integrity-checked SQLite backup.

Switch: --keep N
  Retain the newest N managed database backups. N must be at least 1.

Switch: --reason "TEXT"
  Record the supplied reason in the backup manifest.

Switch: --canlii-api

Switch: --max-pages N
  Limit official discovery pages.

Switch: --max-depth N
  Limit official link-discovery depth.

Switch: --canlii-limit N
  Limit CanLII API records.

Switch: --export-only
  Rebuild historical-judgment JSON from existing SQLite records without collecting.

Switch: --term "TEXT"

Switch: --cap N
  Accepted for command consistency; queue size is used only by queue/all actions.

SEARCH API
--------------------
tools\install-search-helper.cmd
  Install and start the Windows on-logon Search API supervisor task.

Switches: none
  The helper uses the configured loopback ports.

py -u tools\search_supervisor.py
  Run the loopback Search API supervisor on 127.0.0.1:8764.

Switches: none
  Use /wake and /status on the supervisor endpoint.

py -u tools\search_api.py
  Run the local SQLite/FTS5 Search API directly.

Switch: --host ADDRESS
  Bind to a loopback address. Default: 127.0.0.1.

Switch: --port N
  Set the API port. Default: 8765.

Switch: --idle-timeout SECONDS
  Stop after the configured idle period. Default: 300.

py tools\sqlite_concurrency.py
  Enable SQLite WAL mode and concurrency settings before collection or maintenance writes.

Switch: --database PATH
  Configure a different SQLite database. Default: database\bc_justice.db.

Switch: --timeout SECONDS
  Set how long to wait for an existing writer before failing. Default: 60.

NOTES
--------------------
- Use tools\collect-new.cmd for normal operation.
- Manual collection and import commands prompt before backup; scheduled tasks back up automatically.
- Collection stops when a required backup fails.
- Managed database backups are stored in backups\database.
- Runtime data remains in the existing database, imports, reports and generated JSON files.
- CSO security-image completion and record retrieval remain manual; no command bypasses CSO controls.
- Optional CanLII metadata requires CANLII_API_KEY.
- Historical judgment manifest default: imports\historical-judgments\historical-judgments.csv
- The local SQLite/FTS5 API is preferred; static JSON remains the fallback.
